# 胶片暗房

Sony a5100 机内 RAW 后期处理工具。
选择已经拍摄的 ARW，应用滤镜与调色，另存 JPEG 到原生相册。

## 功能

- 支持 RAW、RAW+JPEG 选片与预览
- 15款滤镜
- 亮度、对比度、饱和度调节
- 24M / 12M / 6M JPEG 输出
- 记住上次选择的滤镜
- 支持触屏和实体方向键
- 生成照片可在原生相册回放和管理

## 当前版本

0.8b，本机已验收的稳定版本。

真机验证环境：
- 相机：Sony a5100 / ILCE-5100
- 固件：3.10
- 安装电脑：Windows

其他机型、固件尚未验证。
新用户首次安装流程尚未在另一台空白相机上完整实测。

非索尼官方应用，不要求修改固件。
