Sony a5100 机内 RAW 后期工具：选择已有 ARW / RAW+JPEG，应用 15 款滤镜和调色，另存 JPEG 到原生相册，保留源照片。非 Sony 官方应用。

## 本次更新

- 优化 RAW 解码、渲染、滤镜处理与输出传输，保留逐像素自检及安全回退。
- 保留高光保护、细化后的 -10～+10 调节刻度与 REALA ACE 基础色彩调整。
- 保留调色参数和上次选片记忆；上次照片删除后回到最新照片。
- 保留全部 15 款滤镜及其顺序，24M / 12M / 6M 输出、EXIF、原生相册回放与成片删除。

三项调节的 0/0/0 表示本版校准后的默认效果，并非关闭滤镜或调色。升级会保留或迁移已保存的设置；首次对照时请先确认滑块数值。

## 版本与验证范围

本次发布直接采用已经实机测试的 **0.9.15-compat1（versionCode 24）** APK，仅将下载文件命名为 `FilmDarkroom-0.9.15.apk`；没有修改二进制或重新编译。应用名称仍为「胶片暗房」。

已验证环境：**Sony a5100 / ILCE-5100，固件 3.10**。一次 REALA ACE、24M（6000×4000）、调色 0/0/0 导出记录为 **34.7 秒**，日志显示自检通过及原生相册保存成功。它是单次参考值，不代表所有照片、滤镜、参数或存储卡都能达到相同耗时。非零饱和度、黑白滤镜及其他尺寸的处理路径有所不同。
